# Философ → чат-агент

Собеседник отвечает **по корпусу подлинных сочинений**, а не по общему
представлению модели о философе, и каждая его цитата проверяется механически.
Этот скилл собирает для него **пакет** — данные, которые библиотека
`/Development/aristotle` будет загружать:

```
philosophers/<slug>/
  philosopher.yaml        имя, имя по-английски, годы, группы работ
  works.yaml              реестр работ
  corpus/<работа>/<книга>/<глава>.md
  persona/01-who.md … 05-contract.md
  eval/questions.yaml     вопросы на recall и ловушки
  style/style.md, style/img/, style/fonts/
  SOURCES.md              переводы и права, картинки, шрифты
```

**Что работает сейчас и что ждёт библиотеку.** Go-клиент пока знает одного
Аристотеля: коллекция qmd, перечень групп в инструменте поиска, русские
названия сочинений, картинки страницы зашиты в код. Поэтому пакет сейчас
**собирается и проверяется** (корпус, поиск, персона), но **беседовать** с
философом можно будет, когда библиотека научится открывать пакеты. Код Go в
этой работе не трогать.

## Образец

Аристотель в корне репозитория — эталон. Прежде чем начать, прочесть:

- `persona/01-who.md` … `05-contract.md` — как выглядит готовая персона;
- `build/works.yaml` и `SOURCES.md` — реестр и разбор прав;
- `eval/questions.yaml` — вопросы и ловушки;
- `docs/superpowers/specs/2026-08-31-aristotle-chat-agent-design.md`,
  разделы 3–5 и 8 — почему всё устроено так.

Файлы Аристотеля не править: пакет — отдельный каталог.

## Правило, ради которого всё

**Ничего по памяти.** Год перевода, адрес источника, номер главы, цитата —
всё проверяется в день работы и записывается с датой. Модель путает книги и
главы, приписывает философам чужие сочинения и сочиняет правдоподобные цитаты;
пакет, собранный по памяти, несёт эти ошибки в каждую беседу.

## Шесть этапов

Каждый этап кончается **воротами** — проверкой с командой и ожидаемым
результатом. Следующий этап не начинается, пока ворота не пройдены; результат
каждой проверки — число или вывод команды — идёт в итоговый отчёт.

### 1. Источники и права → `references/sources-and-rights.md`

Список работ: подлинные, спорные и ложно приписываемые (последние понадобятся
персоне, а не корпусу). Для каждой работы — английский перевод в общественном
достоянии: переводчик, год и страна **первой публикации именно этого
перевода**, адрес текстовой версии. Каждый адрес скачать и посмотреть глазами.

**Ворота:** таблица полная; каждый перевод — в общественном достоянии в США на
дату сборки или вынесен в исключение с разбором (образец — «On the Soul» в
корневом `SOURCES.md`). **До ворот ничего не скачивать в корпус.**

### 2. Реестр, разборщики, корпус

1. `philosophers/<slug>/philosopher.yaml`:
   ```yaml
   name: Эпиктет
   name_en: Epictetus
   years: "ок. 50 – ок. 135"
   groups: [ethics, logic, physics]
   ```
   `slug` — строчная латиница и дефисы. `groups` — области, на которые делится
   корпус; поиск сужает по ним выдачу, поэтому их немного (три–восемь) и они
   отражают деление самого философа, а не современных учебников.
2. `works.yaml` — по образцу `build/works.yaml`: `title`, `group`,
   `authenticity`, `source`, `url`, `translator`, `year`.
3. Источник `mit` или `wikisource` — разборщики уже есть. Другой источник —
   новый `build/parse_<источник>.py` с фикстурой, вырезанной из живого файла,
   и тестами по образцу `build/tests/test_parse_mit.py`; затем строка в
   `registry.SOURCES` и ветка в `build._chapters`. Правила границ глав брать
   из живых файлов, а не из догадки (см. ловушки в
   `references/sources-and-rights.md`).
4. `make corpus PHILOSOPHER=<slug>`.

Глава — законченный ход рассуждения, один файл на главу; ссылка вида
`<Title> <Книга>.<Глава>` строится сама.

**Ворота:** `make test-py` зелёный; сборка печатает правдоподобное число глав
по каждой работе (сверить с оглавлением источника); три главы — начало,
середина и конец разных работ — сверены с источником глазами.

### 3. Индекс и recall

1. `make index PHILOSOPHER=<slug>` — минуты на эмбеддинги.
2. `philosophers/<slug>/eval/questions.yaml` — формат как у
   `eval/questions.yaml`: не меньше **семи** вопросов на recall с ожидаемой
   главой (`ask` наивными словами человека, не в терминах корпуса) и **три
   ловушки** с `note`: о сочинении, которое ему ложно приписывают; о
   современной вещи, которой он знать не мог (должен спросить, что это и ради
   чего); о том, о чём корпус молчит (должен признать и перейти в `вывод`).
3. `make recall PHILOSOPHER=<slug>`.

**Ворота:** recall не ниже **5 из 7**. Каждый промах повторить запросом в
понятиях корпуса (`qmd query -c <slug> -- "<понятия>"`); нашлось — понятие
идёт в карту позиций `04-doctrine.md`; не нашлось и так — разобраться,
есть ли эта глава в корпусе.

### 4. Персона → `references/persona.md`

Пять файлов по ролям и размерам из `references/persona.md`. Разделы 2–4
`05-contract.md` — контракт с клиентом, их копировать дословно.

**Ворота** (из корня репозитория, `P=philosophers/<slug>`):

```bash
# каждая выдержка en: найдена в главе, на которую ссылается её cite:
awk '/^>> cite: ./{c=substr($0,10)} /^>> en: ./{print c "\t" substr($0,8)}' $P/persona/*.md |
while IFS=$'\t' read -r cite en; do
  f=$(grep -rlF "cite: \"$cite\"" $P/corpus)
  if [ -n "$f" ] && grep -qiF -- "$en" $f; then echo "ok   $cite"; else echo "FAIL $cite :: $en"; fi
done

# разделы 2–4 контракта совпадают с эталоном; отличаться может только пример cite
diff <(sed -n '/^## 2\./,/^## 5\./{/^## 5\./!p}' persona/05-contract.md) \
     <(sed -n '/^## 2\./,/^## 5\./{/^## 5\./!p}' $P/persona/05-contract.md)

wc -m $P/persona/*.md
```

Ни одного `FAIL`; `diff` показывает только строку с примером ссылки; размеры
в пределах таблицы из `references/persona.md`. Ссылки на главы в `03` и `04`
(«НЭ II.6») механически не проверяются — выписать каждую рядом с путём главы
в корпусе, которой она соответствует, и приложить к отчёту.

### 5. Стиль → `references/style.md`

`style/style.md`: палитра, шрифты, мотив и эпоха, перечень изображений с
назначением; файлы — в `style/img/` и `style/fonts/`; раздел «Веб-интерфейс»
в `SOURCES.md` пакета.

**Ворота:** лицензия каждого изображения прочитана на его странице Commons в
день работы (дата записана); каждый шрифт — под OFL, файл лицензии рядом;
шрифты покрывают кириллицу и письменности, которые цитирует персона.

### 6. Отчёт

Что готово; каждые ворота — с числом или выводом команды; что ждёт
библиотеку: беседа, группы в инструменте поиска, русские названия сочинений,
страница. Непройденные проверки называть прямо.

## Чего не делать

- Цитат по памяти и строк `en:`, не найденных в своей главе.
- `[факт]` об этике, политике, праве: там нет позднейшего знания, которое
  что-то опровергло, есть иные взгляды.
- Нравственных приговоров и «сегодня мы понимаем» в `[посылка]`.
- Текстов ложно приписываемых сочинений в корпусе — их список живёт в персоне.
- Разбора HTML там, где есть текстовая версия, и снятия чужих обёрток
  (кэш поисковика, прокси).
- Изображений без проверенной лицензии и шрифтов не под OFL.
- Правок Go-кода и файлов Аристотеля.
