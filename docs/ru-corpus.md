# Русский корпус

## Назначение

`corpus-ru/` — русский корпус сочинений Аристотеля, собранный из сканов
четырёхтомника «Философское наследие» (М.: Мысль, 1976–1983). Он лежит в
репозитории рядом с английским `corpus/`: один каталог на язык, одна коллекция
qmd на язык. Права на переводы — в разделе «Права» ниже.

Формат: один markdown-файл на главу, frontmatter как у английского корпуса;
книги — подкаталогами `i`, `ii`, … там, где работа делится на книги.

## Права

Переводы и редактура издания 1976–1983 гг. охраняются авторским правом.
Корпус включён в репозиторий по решению владельца; публикация, распространение
и иное использование текстов требуют отдельной правовой оценки. Отдельные
переводы старше срока охраны (Э. Л. Радлов, 1891; С. А. Жебелев, 1911), но
подготовка и примечания издания 1978/1983 гг. могут охраняться.

## Сборка

Полная сборка всех работ, описанных в `build/works_ru/*.yaml`:

```bash
cd build && venv/bin/python pdf_corpus.py --all
```

Отдельные работы — по слагам:

```bash
cd build && venv/bin/python pdf_corpus.py metaphysics on-the-soul
```

По умолчанию результат пишется в `corpus-ru/` в корне репозитория; другой
каталог задаётся через `--out`. Исходные PDF берутся из `~/Downloads/`;
координатный слой и OCR-текст кешируются в `build/.cache/` (каталог в
`.gitignore`).

Работы вне четырёхтомника собираются `build/import_extra.py` из файлов в
`~/Downloads/Aristotel` (mobi/djvu/pdf) с `source: file` — см. отдельный раздел
ниже.

## Индексация для qmd

Русский корпус — отдельная коллекция `aristotle-ru`, чтобы поиск не смешивал
его с английским:

```bash
make index-ru
# то же вручную:
qmd collection add "$PWD/corpus-ru" --name aristotle-ru --pattern '**/*.md'
qmd context add qmd://aristotle-ru/ "Полный русский корпус Аристотеля…"
qmd embed -c aristotle-ru
```

После пересборки корпуса индекс надо освежить:

```bash
qmd update          # перечитать изменённые файлы
qmd embed -c aristotle-ru
```

Проверка:

```bash
qmd status
qmd search "добродетель" -c aristotle-ru
qmd query -c aristotle-ru -- "что такое добродетель"
```

Индекс qmd лежит вне репозитория (`~/.cache/qmd/index.sqlite`); сам корпус
`corpus-ru/` входит в репозиторий.

В веб-панели кнопки **EN / RU** переключают язык корпуса для библиотеки и
беседы: выбор запоминается в браузере, оглавление, чтение главы, поиск
библиотеки и `search_corpus` в беседе идут в выбранный корпус
(`corpus/` + `aristotle` или `corpus-ru/` + `aristotle-ru`). В русском режиме
к персоне добавляется правило: искать по-русски, `cite` — русский заголовок
главы, `en` — дословная русская выдержка (по ней идёт сверка), `ru` повторяет
её для показа. Старые ответы помнят свой язык: панель источников берёт главу
из того корпуса, откуда пришла врезка.

## Проверка

```bash
cd build && venv/bin/python -m pytest -q          # 157 тестов
```

Число глав по книгам сверяется с английским `corpus/<slug>/` — как вручную, так
и автоматически: `pdf_corpus.py` сравнивает количество глав по каждой книге и
печатает предупреждение при расхождении. В готовом тексте не должно остаться
строк-заголовков `ГЛАВА`/`КНИГА` и одиноких чисел-страниц:

```bash
grep -rnE '^(ГЛАВА|КНИГА|КПИГА|КИНГА)' corpus-ru/
grep -rhoE '^[0-9]{2,4}$' corpus-ru/ | sort -u
```

Обе команды должны ничего не вывести.

## Известные расхождения

Это не ошибки сборки, а разные членения изданий:

- **«Политика»** (том 4) делит книги на меньшее число глав, чем английский
  корпус. Фактически: i=5, ii=9, iii=12, iv=10, v=10, vi=5, vii=15, viii=7
  (73 главы против 103). Сборщик печатает предупреждение; подгонять границы
  под английский нельзя — в русском издании их просто нет.
- **«Топика»**, книга V: в издании 1978 г. напечатана «ГЛАВА ДЕВЯТАЯ»
  (PDF с. 456), поэтому 9 глав против 8 в английском корпусе.
- **«Большая этика»** собирается через OCR (tesseract): номера глав местами
  читаются как `{.`, `1{7.`; `pdf_corpus.fix_numbered_ocr` выправляет их по
  порядку, поэтому глав ровно 51 (книга I — 34, книга II — 17).

## Работы вне четырёхтомника

Собираются из файлов в `~/Downloads/Aristotel`:

```bash
cd build && venv/bin/python import_extra.py --all
```

Текст конвертируется в `build/.cache/extra/` (`ebook-convert` для mobi/djvu,
`pdftotext` для pdf) и режется по разметке конкретного издания.

| работа | слаг | переводчик | год | глав |
|---|---|---|---|---|
| Афинская полития | `athenian-constitution` | С. И. Радциг | 1997 | 69 |
| История животных | `history-of-animals` | В. П. Карпов | 1996 | 220 |
| О чувственном восприятии | `on-sense-and-the-sensible` | Е. В. Алымова | 2004 | 7 |
| О памяти | `on-memory` | Е. В. Алымова | 2004 | 2 |
| О сновидениях | `on-dreams` | С. В. Месяц | 2024 | 3 |
| О частях животных | `parts-of-animals` | В. П. Карпов | 1937 | 4 книги (файл на книгу) |
| О возникновении животных | `generation-of-animals` | В. П. Карпов | 1940 | 5 книг (файл на книгу) |

Во фронтматтере у них `source: file`. «Афинская полития», «О чувственном
восприятии», «О памяти» и «О сновидениях» совпадают с английским корпусом по
числу глав. «История животных»: книги I–VII совпадают полностью
(17, 17, 22, 11, 34, 37, 12); в книгах VIII–IX издание печатает меньше глав
(27 и 43 против 30 и 50), десятая («спорная») книга в английском корпусе
отсутствует и в русский не включена.

«О частях животных» и «О возникновении животных» в изданиях 1937/1940 гг.
делятся **только на книги**, глав в них нет вообще (в оглавлении перечислены
лишь книги). Поэтому для них собран один файл на книгу: `parts-of-animals/i/`…
`iv/`, `generation-of-animals/i/`…`v/`, в каждом `01.md`. Это не беккеровское
членение английского корпуса; для qmd такие файлы можно нарезать иначе.
