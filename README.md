# Аристотель

Корпус английских переводов Аристотеля, собранный по главам, плюс (в
будущих задачах) чат-агент, который отвечает в духе Аристотеля и подкрепляет
сказанное проверяемыми цитатами из этого корпуса.

Сейчас в репозитории готова только первая часть — корпус и конвейер его
сборки. Агент — предмет отдельных задач плана, см. `docs/superpowers/`.

## Что здесь есть

- `corpus/` — 1409 файлов markdown, по одному на главу: **29 подлинных
  работ** Аристотеля на английском (20 с Internet Classics Archive при MIT,
  9 с Wikisource). Каждый файл несёт YAML-шапку с работой, книгой, главой,
  группой (`logic`, `physics`, `psychology`, `biology`, `metaphysics`,
  `ethics`, `politics`, `rhetoric-poetics`), признаком подлинности и
  переводчиком.
- `build/` — конвейер сборки на Python: `works.yaml` (реестр работ),
  `fetch.py`, `parse_mit.py`, `parse_ws.py`, `emit.py`, `sources.py`,
  `build.py` и тесты в `build/tests/`.
- `SOURCES.md` — таблица всех 29 работ с переводчиками и числом глав, и
  обоснование прав на воспроизведение текста.
- `docs/superpowers/` — спецификация и план всего проекта, включая
  нереализованную пока часть с агентом на Go.

## Как собрать корпус

Единственная рантайм-зависимость — PyYAML; для тестов ещё нужен pytest.

```bash
cd build
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt

python build.py            # собрать в corpus/, не трогая уже скачанное
python build.py --force    # пересобрать с нуля (снесёт corpus/ перед сборкой)
```

Сборка читает `works.yaml`, качает тексты (с кэшем в `build/.cache/`),
разбирает их по главам и пишет `corpus/<work_slug>/<book>/<chapter>.md`.
В конце перезаписывается `SOURCES.md` с фактическим числом глав и
переводчиком, найденным в самом тексте (если реестр его не переопределяет).

Тесты:

```bash
cd build && python -m pytest tests/ -v
```

## Как завести поисковую коллекцию qmd

Корпус ищется через `qmd` — локальный поисковый индекс с семантическим
поиском, общий для всех проектов на машине. Коллекция заводится отдельно от
кода репозитория, в общем индексе qmd:

```bash
qmd collection add aristotle /path/to/aristotle/corpus --pattern '**/*.md'
qmd context add qmd://aristotle/ "Полный корпус Аристотеля по-английски, один файл на главу, с полями authenticity и group во frontmatter"
qmd embed -c aristotle
qmd status
```

`qmd embed` на 1409 файлах занимает несколько минут — это разовая цена,
эмбеддинги остаются в индексе qmd. Если `qmd collection add` сообщит, что
коллекция уже существует, пересоздавать её не нужно — можно сразу переходить
к `qmd embed`.

Проверка, что поиск действительно находит нужное:

```bash
qmd query "what is happiness the good for man" -c aristotle --json -n 5
```

Среди попаданий должна быть глава `nicomachean-ethics/i/07.md` — именно там
Аристотель определяет счастье как деятельность души сообразно добродетели.

## Чего в корпусе нет и почему

Полный список сочинений, которые когда-либо приписывались Аристотелю, шире
29 собранных работ. Часть отсутствующего — недостижима из доступных
источников, а не выброшена по выбору:

- **«Евдемова этика»**, **«О растениях»** и **«О добродетелях и пороках»**
  на Wikisource физически лежат трансклюзиями Proofread-Page (все три —
  из одного скана, «Works of Aristotle v9»): и на корневой странице, и на
  подстраницах сырой wikitext содержит только тег `<pages index="..."
  from=... to=... />` — самого текста в нём нет, он существует только как
  отрисованный HTML постранично отсканированного тома.
- **«Проблемы»** — страницы с этим именем на Wikisource нет вовсе: заголовок
  `Problems` оказался редиректом на постороннее, не аристотелевское
  произведение (стихотворение Эмили Дикинсон).

Достать эти четыре работы можно было бы только через разбор отрисованного
HTML вместо сырого текста — конвейер сознательно на это не идёт (см. раздел
о правах в `SOURCES.md`: работа с текстовыми версиями и сырым wikitext,
а не с HTML-вёрсткой, часть той же аргументации). Другие традиционно
приписываемые Аристотелю, но не принадлежащие ему сочинения («О мире»,
«Риторика к Александру», «Механика», «Экономика», «О цветах», «О чудесных
слухах») на Wikisource не представлены вовсе — их не с чего собирать.

Итог: индексируется корпус из 29 работ, все — подлинные
(`authenticity: genuine`). Способность агента ответить «этого я не писал»
на вопрос о неаутентичном сочинении не требует текста этого сочинения —
она будет держаться на списке ложно приписываемых работ в персоне агента,
а не на индексации их текстов.

## Права на тексты

Раздел с обоснованием прав на воспроизведение текстов из `corpus/` — в
[`SOURCES.md`](SOURCES.md). Коротко: тексты в общественном достоянии,
лицензия `LICENSE` (MIT) на них не распространяется и покрывает только код
этого репозитория.
