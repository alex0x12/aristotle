# Аристотель

Собеседник, который отвечает как Аристотель — опираясь не на общее
представление модели о нём, а на индексированный корпус его подлинных
сочинений.

Отличие от «поговори с философом» в промпте одно, но существенное:
**каждая цитата проверяется механически.** Когда собеседник ссылается на
главу, клиент сверяет приведённые слова с текстом именно той главы — и, если
их там нет, печатает пометку прямо в ответе, а не прячет в журнал.

## Как это выглядит

Дословный кусок живого прогона:

```
> Что такое добродетель?

Добродетель надвое: одна — мыслительная, другая — нравственная. Первая
рождается и растёт от обучения; вторая — от привычки, откуда и само имя её
образовано от ἔθος.

│ нравственная добродетель возникает как следствие привычки
│ — Nicomachean Ethics II.1

Строителем становятся, строя, кифаристом — играя на кифаре; так и
справедливым — совершая справедливое.

│ добродетель есть склад души, связанный с выбором, состоящий в обладании
│ серединой
│ — Nicomachean Ethics II.6

Итак, добродетель — склад души, связанный с выбором, состоящий в обладании
серединой — но серединой не арифметической, а относительно нас: Милону
положено не то, что начинающему.

Две оговорки. Во-первых, не всякое действие допускает середину:
прелюбодеяние, воровство, убийство уже самими именами обозначают дурное.
Во-вторых, не требуй от этого ответа точности математики: речь о делах
ведётся в общих чертах, как и о здоровье.
```

Обе врезки — настоящие цитаты из указанных глав, поэтому пометки нет.
Если бы модель сослалась на главу, где такой строки нет, вторая строка
врезки читалась бы так: `— Nicomachean Ethics II.6  [!] нет в выдержках`.

## Быстрый старт

```bash
make build && make run
```

Или без `make`:

```bash
go build -o aristotle ./cmd/aristotle
./aristotle
```

Запускать из корня репозитория — бинарник ищет рядом `persona/` и `corpus/`;
из другого места помогает `-root /путь/до/aristotle`.

Чтобы `aristotle` запускался из любого каталога, поставьте его в
`~/.local/bin`:

```bash
make install       # другое место — make install PREFIX=/usr/local
make uninstall     # убрать
```

Путь к репозиторию вписывается в бинарник при сборке (значение `-root` по
умолчанию), так что репозиторий должен оставаться на месте; переместили его —
повторите `make install` и `make index`.

Нужен ключ API провайдера, совместимого с OpenAI. По умолчанию это DeepSeek:
адрес `https://api.deepseek.com/v1`, модель `deepseek-flash`. Модель одна,
профилей нет. Ключ сохраняется одной командой; ввод на экране не
показывается:

```bash
./aristotle key           # одна строка со стандартного ввода
./aristotle key -delete   # удалить сохранённый ключ
```

Ключ лежит только в `~/.config/aristotle/keys.json` (права 0600); переменные
окружения для ключа не читаются. Адрес API, название модели, усилие
размышления и бюджет контекста — в `~/.config/aristotle/config.json` или в окне настроек
веб-интерфейса. Другой OpenAI-совместимый адрес (например, OpenRouter, через
который доступны и другие модели) задаётся там же. Поиск по умолчанию
возвращает 6 глав — модель может попросить другое число.

Режим размышления включён всегда: запрос идёт с параметрами `thinking` и
`reasoning_effort` из документации DeepSeek. Усилие (`reasoning_effort` в
`config.json`) — `low`, `high` или `max`, по умолчанию `high`. С `max` модель
думает около минуты на каждый запрос, а за ход их бывает до пяти (поиски и
ответ), так что ответ ждётся 3–4 минуты; пока она думает, под беседой
написано «размышляю» и сколько длится ход. Если сервер их не принимает (другой провайдер), запрос один раз
повторяется без них, и выводится одно предупреждение. Рассуждение модели в
журнал сохраняется (поле `reasoning`): сервер требует присылать его назад в
следующих запросах, а после перезапуска беседа собирается из журнала. На
экране и в выгрузке рассуждения нет. У записей старых журналов его нет, и в
запрос они уходят без него.

Поиск по корпусу идёт через [`qmd`](https://github.com/jerpint/qmd) —
локальный индекс с семантическим поиском. После клонирования его нужно
завести один раз: `make index` (несколько минут на эмбеддинги).

## Веб-интерфейс

```bash
make web            # или ./aristotle web
```

Откроется браузер на `http://127.0.0.1:8337/`: беседы слева, разговор в
середине, справа — глава, на которую сослался ответ, с подсвеченной
выдержкой. Пометки — те же, что описаны ниже. Здесь же библиотека корпуса и
настройки.

Флаги: `-addr 127.0.0.1:8337`, `-no-open` — не открывать браузер, `-root` —
откуда брать `persona/` и `corpus/`, как у консоли. Остановка — Ctrl-C.

**Только этот компьютер.** `-addr` принимает лишь `localhost`, `127.0.0.1`
и `::1` (в адресе — `[::1]:8337`). Запрос с чужим `Host` сервер отклоняет (защита от DNS rebinding), а
запрос, меняющий состояние, принимает только со своей же страницы (`Origin`):
ключи управляются отсюда, и страница с другого сайта до них дотянуться не
должна.

**Беседы.** Журналы — те же файлы, что и у консоли,
`~/.local/share/aristotle/*.jsonl`. Консольные беседы видны в списке (в старых
журналах сверка цитат не сохранена, и это помечено), а веб-беседу можно
продолжить в консоли:
`./aristotle -resume ~/.local/share/aristotle/<имя>.jsonl`. Удалённая
беседа не стирается, а переезжает в `~/.local/share/aristotle/trash/`.
«ЭКСПОРТ .MD» отдаёт беседу в Markdown: вопросы, ответы, врезки с русским
названием работы и английской ссылкой рядом.

**Библиотека.** Работы → книги → главы → чтение главы. Названия работ
по-русски, английское название под ним. Поиск по корпусу — тот же, что у
модели, поэтому ему нужны `qmd` и построенный индекс (`make index`); без них
поиск ответит ошибкой, а остальное в библиотеке работает. Кнопки **EN / RU**
переключают библиотеку и беседу на локальный русский корпус (`corpus-ru/`,
коллекция `aristotle-ru`, `make index-ru`); выбор запоминается в браузере и
меняет и `search_corpus` следующего хода.

**Ключ.** Хранится только в `~/.config/aristotle/keys.json` (права 0600,
запись атомарная) и подхватывается и консолью. Ключ задаётся в окне настроек
или командой `aristotle key`. Назад в браузер он не приходит: интерфейс
показывает лишь подсказку с последними четырьмя символами. Кнопка
«Проверить» делает бесплатный запрос списка моделей (`GET …/models`) по
сохранённому адресу и токенов не тратит. Пока ключа нет, над полем ввода
стоит подсказка про «Настройки».

**Настройки** — четыре поля: адрес API, модель, ключ и бюджет контекста
(0 — без урезания). Правки действуют сразу, перезапуск не нужен. Если
`config.json` не читается (в том числе если он в старом формате с
профилями), интерфейс работает на настройках по умолчанию и говорит об этом
баннером; сохранение настроек заменяет файл, а прежний копируется рядом как
`config.json.bad-<время>`.

**Расход.** Вкладка «Расход» считает по дням и моделям токены — вход, выход,
чтение из кэша — прямо из журналов. Цен и стоимости нет нигде. Знак `≈` —
сумма неполная: ответ оборвался, и провайдер не назвал токенов. Удалённые
беседы в сумме остаются: их журналы лежат в `trash/`.

**Бюджет контекста** — потолок входа одного запроса в токенах (по умолчанию
128000). Размер
оценивается по числу знаков (рассуждения прежних ответов входят в
контекст и тоже считаются) и уточняется по данным провайдера. Когда беседа
бюджет перерастает, сперва опускается текст старых выдержек, потом старые
ходы целиком, начиная с самых ранних. Первый ход и текущий остаются всегда.
В журнале и на экране беседа остаётся целой; линия «раньше этого места
философ не видит» показывает границу. Если и после урезания запрос не
умещается, он уходит в урезанном виде, с предупреждением «бюджет превышен и
после урезания». Бюджет работает и в консоли: она пишет, сколько опущено.

Изображения и шрифт встроены в бинарник; откуда они и под какими правами —
в [`SOURCES.md`](SOURCES.md).

## Что означают пометки

Ответ размечен, и разметка несёт смысл.

**Врезка со ссылкой** — цитата из корпуса. Английский оригинал доступен
командой `/src`: русский текст в ответе — перевод перевода, и выдавать его
за слова Аристотеля было бы нечестно.

**`[!] нет в выдержках`** — приведённых слов в заявленной главе нет.
Механическая проверка, без доверия модели на слово.

**`[вывод]`** — то, чего в корпусе нет. Современные вопросы — выгорание,
криптовалюта, ваш код — переводятся в его понятия и разбираются по его
началам. Помечено, потому что это следствие, а не цитата.

**`[факт]`** — позднейшее знание установило иное. Только естествознание:
самозарождение из гнили, неподвижная Земля, сердце как орган мышления.

**`[посылка]`** — на чём держится довод и где он трещит по его же меркам.
Например, в «Политике» I.6 Аристотель сам признаёт, что рабство по закону
с рабством по природе не совпадает.

Правило, которого агент держится: **там, где корпус отвечает, ответ
Аристотеля и есть ответ.** Он не пересматривает свои взгляды задним числом
и не подгоняет их под взгляды собеседника — иначе это была бы не его
позиция, а догадка о том, что он подумал бы сегодня. Сноски показывают
устройство довода, но не выносят приговор.

## Команды

В беседе: `/src` — английские оригиналы выдержек последнего ответа;
`/again` — повторить вопрос; `/quit` — выйти.

Флаги: `-root`, `-resume <журнал.jsonl>`, `-eval <файл>`, `-recall-only`.
Подкоманды: `web` запускает веб-интерфейс (флаги — в разделе о нём), `key`
сохраняет ключ API (`key -delete` — удаляет).

Цели `make`: `build`, `run`, `web`, `install`, `uninstall`, `check`, `test`,
`eval`, `eval-recall`, `corpus`, `corpus-force`, `index`, `recall`, `assets`,
`install-skill`, `uninstall-skill`, `clean`. Справка — `make help`.
`assets` заново скачивает изображения и шрифт веб-интерфейса; результат и
так лежит в git, так что нужен он только при смене набора.

## Как устроено

Агент на Go, сборка корпуса на Python.

- `cmd/aristotle/` — CLI: флаги, цикл беседы, подкоманды замеров и `web`.
- `internal/chat/` — ход беседы: модель просит поиск, цикл его выполняет,
  отдаёт главы и даёт ответить. Не больше четырёх обращений за ход.
- `internal/corpus/` — поиск поверх `qmd` и разбор глав.
- `internal/render/` — разбор разметки в потоке, сверка цитат, печать.
- `internal/provider/` — одна реализация на все OpenAI-совместимые API,
  с режимом размышления.
- `internal/web/` — веб-интерфейс: сервер и встроенная страница
  (`static/`: скрипты, стили, изображения, шрифт).
- `internal/app/`, `internal/config/`, `internal/keys/` — общее для консоли
  и веба: пути, подключение (адрес, модель, бюджет), ключ.
- `persona/` — пять файлов, из которых собирается системный промпт:
  биография, голос, метод, карта позиций, правила ответа.
- `corpus/` — 1411 файлов, по одному на главу; 29 подлинных работ,
  20 с Internet Classics Archive при MIT и 9 с Wikisource. Коммитится
  целиком: клонировал — работает.
- `build/` — конвейер сборки корпуса.
- `skills/` — скилл для Claude: как собрать пакет философа.
- `eval/questions.yaml` — контрольные вопросы для замеров.
- `docs/superpowers/` — спецификация и план разработки.

## Замеры

Точка отсчёта для правок персоны. Признак правки, которая стоит внимания:
recall упал или выдумки перестали быть нулевыми.

Дата 1 сентября 2026, профиль `deepseek`.

- **Выдуманных выдержек: 0 из 13.** Десять вопросов, каждый на свежей
  сессии.
- **Recall@6 при наивном запросе: 5/7.** Это нижняя граница, а не оценка
  системы: набор подаёт вопрос в поиск дословно, а живой агент
  переформулирует его в понятиях корпуса и может искать до четырёх раз.
  Обе промахнувшиеся главы находятся первой строкой при запросе в понятиях
  корпуса.
- **Поиск:** первый вызов в сессии 8–9 с (загрузка локальных моделей `qmd`),
  дальше 2,5–3 с.

Быстрый прогон без трат на API: `make eval-recall`.

## Другие философы

Библиотека задумана на многих философов; код пока знает одного Аристотеля.
Пакет нового философа собирается заранее в `philosophers/<slug>/` — реестр
работ, корпус, пять файлов персоны, контрольные вопросы, стиль страницы — по
скиллу Claude `skills/philosopher-agent/` (`make install-skill` ставит его
ссылкой в `~/.claude/skills`). Для пакета работают `make corpus`,
`make index` и `make recall` с `PHILOSOPHER=<slug>`; беседовать с ним можно
будет, когда библиотека научится открывать пакеты.

## Чего здесь намеренно нет

- **Нумерации Беккера** — источники её не несут. Ссылка на книгу и главу
  проверяема и без неё.
- **Русского корпуса в репозитории** — переводы охраняются и лежат локально в
  `corpus-ru/`; для поиска он индексируется отдельной коллекцией `aristotle-ru`
  (`make index-ru`) и в git не попадает.
- **Локальной модели** — на доступном железе она не удержала бы
  одновременно персону, выдержки и качество отыгрыша.
- **Псевдо-аристотелевских сочинений.** «О мире», «Механика», «Экономика»,
  «Проблемы» и прочие ему не принадлежат — и их текстов нет ни в одном из
  двух источников в пригодном для разбора виде: на Wikisource они лежат
  трансклюзиями без самого текста либо отсутствуют, на MIT их не было
  никогда. Поэтому способность агента сказать «этого я не писал» держится
  на списке в персоне, а не на индексации подлога.

## Права

Тексты в `corpus/` — переводы в общественном достоянии; лицензия `LICENSE`
(MIT) покрывает только код. Исключение одно: перевод «О душе» Смита издан
в 1931 году и в США остаётся под охраной до 1 января 2027 года.

Изображения веб-интерфейса — с Wikimedia Commons, где они помечены как
общественное достояние; шрифт Alegreya — под SIL Open Font License 1.1.

Обоснование, таблица переводчиков с годами изданий и разбор этого
исключения, а также источники изображений, шрифта и русских названий
сочинений — в [`SOURCES.md`](SOURCES.md).
